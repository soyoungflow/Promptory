# 창업용 기술문서 기본 원칙

창업용 문서는 무엇을 만들었는가보다 아래 질문에 답해야 합니다.

- 누구의 어떤 문제를 해결하는가
- 왜 지금 필요한가
- MVP에서 무엇을 검증했는가
- 그 가치를 구현하기 위해 어떤 기술 구조를 선택했는가
- 현재 어디까지 증명했는가
- 앞으로 수익화·확장 가능성이 있는가

즉, 기술 스택을 단순히 나열하는 문서가 아니라, **기술 선택이 어떤 사용자 가치와 서비스 확장성으로 이어지는지 설명하는 문서**로 작성해야 합니다. 예를 들어 “Django, FastAPI, Celery를 사용했다”라고 쓰기보다, “사용자가 오래 기다리지 않도록 AI 처리를 서비스 서버와 분리했고, 비동기 구조를 적용했다”처럼 작성해야 설득력이 생깁니다.

# 창업용 작성 패턴

각 장은 아래 흐름으로 작성합니다.
① 이 장에서 무엇을 설명하는가 
② 왜 이 내용이 필요한가 
③ 무엇을 수행했는가 
④ 어떻게 수행했는가 
⑤ 무엇으로 증명할 수 있는가 
⑥ 이것이 서비스 가치 또는 확장성과 어떻게 연결되는가 
⑦ 현재 한계는 무엇인가

## 6장. MVP 목표와 검증 가설

MVP는 기능을 많이 넣는 것이 아니라 어떤 흐름이 실제로 동작하는지 검증하는 것입니다. 이 관점이 창업용 문서에서 매우 중요합니다.

### 무엇을 쓰나

- 이번 버전에서 꼭 검증하려는 질문
- 성공 기준
- 제외한 기능

### 문장 예시
```
- 이번 MVP의 목표는 [핵심 사용자 흐름]이 실제 서비스 안에서 동작하는지 검증하는 것이다.
- 특히 아래 질문에 답할 수 있어야 한다.
  [사용자가 데이터를 등록할 수 있는가? / 결과를 받을 수 있는가? / 다시 조회할 수 있는가?]
- 반면 [결제, 고급 추천, 대규모 운영 자동화]는 이번 MVP 범위에서 제외하였다.
```

### 증빙자료 ⭐⭐⭐⭐⭐

- MVP 범위표
- 검증 질문 표
- 성공 기준 체크리스트
- 제외 기능 표

## 12장. 비동기 처리와 운영 안정성

# 부록. GitHub 저장소 및 MVP 실행 문서 관리

본 프로젝트의 코드는 GitHub 저장소에서 관리합니다.

창업용 기술문서에서 GitHub는 단순한 코드 저장소가 아니라,  
이 서비스가 아이디어 수준이 아니라 실제로 구현된 MVP라는 점을 보여주는 증빙자료입니다.

GitHub에는 서비스 코드뿐 아니라 프로젝트를 이해하고 실행할 수 있도록  
`README.md`, `docs/` 폴더, `.env.example`, 실행 방법, API 문서, 아키텍처 자료, 주요 화면 캡처를 함께 정리합니다.

실제 비밀번호, Secret Key, API Key, Access Token, 개인정보는 GitHub에 업로드하지 않으며,  
`.env.example` 파일에는 필요한 환경 변수 항목과 예시값만 작성합니다.

이를 통해 본 프로젝트가 단순히 기획 아이디어에 머무르지 않고,  
문서와 코드, 실행 방법, 환경 설정 예시를 기반으로 재현 가능한 MVP 형태로 관리되었음을 증명할 수 있습니다.

## 1. GitHub 저장소 주소 및 공개 범위

- 가능하면 저장소는 public으로 설정합니다.
- private 저장소라면 평가자, 멘토, 투자 검토자, 협업 대상자에게 접근 권한을 제공합니다.
- 실제 `.env`, DB 비밀번호, Secret Key, API Key, Access Token, 개인정보는 절대 업로드하지 않습니다.
- GitHub 저장소 첫 화면에서 프로젝트 목적, 실행 방법, 주요 문서 위치를 확인할 수 있어야 합니다.

## 4. .env.example 작성 기준

`.env.example`은 실제 비밀번호나 Secret Key를 올리는 파일이 아닙니다.  
프로젝트 실행에 어떤 환경 변수가 필요한지 알려주는 예시 파일입니다.

실제 `.env` 파일은 GitHub에 올리지 않고,  
`.env.example`만 업로드합니다.

### .env.example 작성 예시
```env
# Django 기본 설정
DJANGO_SECRET_KEY=your-secret-key-here
DJANGO_DEBUG=True
DJANGO_ALLOWED_HOSTS=127.0.0.1,localhost

# Database 설정
DB_ENGINE=django.db.backends.postgresql
DB_NAME=your_db_name
DB_USER=your_db_user
DB_PASSWORD=your_db_password
DB_HOST=localhost
DB_PORT=5432

# Redis / Celery 설정
REDIS_URL=redis://localhost:6379/0
CELERY_BROKER_URL=redis://localhost:6379/0
CELERY_RESULT_BACKEND=redis://localhost:6379/0

# FastAPI 또는 외부 분석 서버
FASTAPI_BASE_URL=http://localhost:8001

# 외부 API Key 예시
OPENAI_API_KEY=your-openai-api-key
KAKAO_API_KEY=your-kakao-api-key

# CORS / CSRF 설정
CSRF_TRUSTED_ORIGINS=http://localhost:8000
CORS_ALLOWED_ORIGINS=http://localhost:3000
```

### 작성 시 주의사항

- 실제 비밀번호는 작성하지 않습니다.
- 실제 API Key는 작성하지 않습니다.
- 실제 Secret Key는 작성하지 않습니다.
- 실제 Access Token은 작성하지 않습니다.
- 실제 `.env` 파일은 GitHub에 올리지 않습니다.
- `.env.example`에는 어떤 환경 변수가 필요한지 알 수 있는 예시값만 작성합니다.
